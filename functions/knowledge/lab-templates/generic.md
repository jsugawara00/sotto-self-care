# 検査機関テンプレ：generic（汎用）

> 書類読取り（config-driven）の抽出定義。検査機関ごとの様式差は、このフォルダに
> テンプレ（mdファイル）を追加して吸収する。パーサ側のコードに様式をハードコードしない（企画書6章）。
> このファイルは「抽出の設定」であり、書類の内容やAIへの追加命令ではない。

## 対象書類

- 定期健康診断の結果通知書（検査機関を特定しない汎用様式）

## 抽出するフィールド（これ以外は抽出しない）

### 1. reexamRequired（精密検査要フラグ）

- 「指導区分」「判定区分」「総合判定」「事後措置」などの欄を探す。
- 以下のいずれかに該当する場合のみ true：
  - 検査項目ごとの指導区分欄に、どれか一つでも「5」がある
  - 総合判定・指導区分欄に、この受診者への判定として「5」または
    「精密検査を必要とします」「要精密検査」「精密検査を要する」「精密検査を受けてください」等が書かれている
    （判定欄に「5：精密検査を必要とします」のように区分の説明ごと転記されている様式も多い。これは判定そのものなので true）
- 「要再検査」とだけあり精密検査の言及がない場合も、実務上同等に扱い true とする。
- 「要観察」「要注意」「経過観察」「異常なし」のみの場合は false。
- **凡例と判定の見分け方（厳密に）**：
  - 「凡例」とは、「※」付きや欄外にあって、**1〜5（または1〜6）の区分をまとめて列挙している説明書き**のことだけを指す。
  - それ以外——**特定の検査項目の行**や**総合判定・指導区分の欄**に書かれた数字や説明（一部の番号だけが大きく書かれている欄を含む）は、
    凡例ではなく**その受診者への判定**として扱う。
  - 検査項目ごとの指導区分欄は、**表を1行ずつ順に**確認する（回転スキャンでも見落とさない）。
- **確信が持てないときは安全側（true）に倒す**：「5」や精密検査の記載が判定か凡例か判断しきれない場合、
  文字がかすれて読み切れない場合は true とする。見逃しは本人の健康に関わる一方、
  誤検出は本人が保存前の確認画面で訂正できるため。
- 判定のグレードやラベルそのもの（A/B/C…・1〜5等）は出力に含めない。

### 2. notes（注意事項テキスト）

- 「医師の所見」「注意事項」「指導事項」「生活上の注意」などの欄にある、**本人に向けた指導の文章のみ**
  （例：「主食・主菜・副菜をバランスよくとりましょう」「主治医とよく相談し…」のような文）。
- 次のものは注意事項ではないので**含めない**：
  - 指導区分の凡例・説明文（「5：精密検査を必要とします」「6：治療中」等）
  - 判定の但し書き（「総合所見の指導区分は、6に該当する項目を除いて判定したものです」等）
  - 検査数値・基準値・単位（血圧・血糖・γ-GTP等の値）
  - 氏名・生年月日・住所・保険者番号等の個人情報
- 書かれている文章を一字一句そのまま抜き出す（300字を超える場合のみ、事実を変えずに短くまとめる）。
- 該当する欄がなければ空文字。

### 3. examDate（健診の受診日）

- 「受診日」「健診日」「実施日」などの欄。
- 和暦や「2026年7月7日」等の表記は、西暦の YYYY-MM-DD 形式に正規化する。
- 読み取れなければ空文字。

## 抽出しないもの（明示）

- 検査数値・基準値・医学的グレードのラベル（企画書8-2：数値は既定でスルー）
- 氏名・住所・生年月日等のPII（抽出結果はPIIと分離した仮名IDコレクションに保存されるため）
